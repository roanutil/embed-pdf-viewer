# Swift Wrapper for `i18n` Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Export the workspace `i18n` plugin through UniFFI as `I18nHandle`, wire it into `ViewerHost` behind `ViewerConfig.i18n`, and give Swift an `I18nCapability` plus a `BundleLocaleLoader` that serves lazy locale packs from an app bundle.

**Architecture:** The recipe in `2026-10-01-swift-package.md` Appendix A §A.0, with metadata (`crates/plugins/metadata/src/ffi.rs`) as the template. Two things are new here. The plugin's lazy `Loader` port becomes a foreign trait, `LocaleLoader`, that answers through a completion object instead of a return value, so Swift can read a file off the kernel thread and answer later. That completion is built on a new `epdf_ffi::ForeignSettle<T>`, which parks a kernel `Resolver` and settles it from any thread, and rejects it if Swift drops the completion without answering. Locale packs cross as flat dotted-key maps (`"commands.zoom.in" -> "Zoom in"`), because UniFFI has no recursive records; `locale_pack_from_json` parses the same locale JSON files the web ships.

**Tech Stack:** Rust 2024, `uniffi =0.32.0`, `futures` 0.3, Swift 6.2 tools, Swift Testing, `swift-custom-dump` 1.3, Xcode 27.0, iPhone 17 simulator (iOS 26.0).

**Spec:** `docs/superpowers/plans/2026-10-06-swift-plugins/00-umbrella.md` (order, names, shared files, definition of done) and `docs/superpowers/plans/2026-10-01-swift-package.md` (Global Constraints, Decisions, Appendix A §A.0 and §A.4 "i18n").

## Global Constraints

Every line of the umbrella's Global Constraints applies. The ones this plan meets most often:

- `uniffi` is pinned at `=0.32.0`.
- UniFFI type names are unique across the workspace. Generic names get the plugin prefix: `I18nEvent`, `I18nParam`, `TextDirection` (not `Dir`).
- Types shared by more than one plugin live in `epdf-ffi`. `ForeignSettle<T>` and `HostError` are there already (umbrella Task 0c); plans 14 and 15 use them too.
- No `usize`, `isize`, `Rc` or `serde_json::Value` across the boundary.
- Facades don't decide semantics: lookup, plural selection, negotiation and fallback stay in `crates/plugins/i18n/src`.
- Swift value assertions use `expectNoDifference`.
- No npm package changes, no changesets.

## Review Focus

Each line names an input the happy path never sends, what a person would expect, and the test that pins it.

1. A Swift loader that drops its completion without calling `finish` or `fail`. Expected: the pending `setLocale` rejects with `operation-failed`, it doesn't hang. Pinned in Task 2 (`a_dropped_completion_fails_the_switch`).
2. A loader that answers twice, or answers from a background thread after the switch was superseded. Expected: the first answer wins, the second does nothing, nothing crashes. Pinned in Task 2 (`a_second_answer_is_ignored`).
3. A flat pack where one key is both a leaf and a branch (`"a": "x"` and `"a.b": "y"`). Expected: `invalid-input` naming the key, not a silently dropped string. Pinned in Task 1 (`a_key_that_is_both_leaf_and_branch_is_refused`).
4. Two switches in a row, the first to a lazy pack still loading. Expected: the first call rejects with `operation-cancelled` and the locale ends on the second. Pinned in Task 2 (`a_newer_switch_cancels_the_pending_one`).
5. `ViewerConfig.i18n` listing lazy locales with no loader. Expected: `ViewerHost::new` fails with `invalid-input`, not a switch that can never complete. Pinned in Task 3 (`lazy_locales_without_a_loader_fail_to_build`).

## Decisions

`set_locale` takes no `CancelToken`. The plugin has nothing to abort: a lazy load is the loader's own work, and cancelling the Swift task can't stop Swift's file read. A newer `set_locale` already supersedes an older one. Cancelling the awaiting task therefore doesn't cancel the switch, and the Swift doc comment says so.

`t(_:)` is async, like every other member, because the kernel lives on its own thread. One translated label costs one kernel hop. A SwiftUI view that shows dozens of plugin labels should read them once per locale change (the `localeChanged` event), not once per render. We think that's acceptable for strings that come out of Rust plugins (command labels, plugin chrome); an app's own strings belong in its String Catalog.

Packs cross flat. Lookup splits keys on `.` (`crates/plugins/i18n/src/translate.rs` `lookup`), so a dotted flat key reaches exactly what the nested key reached. One difference: a JSON key that itself contains a dot (`{"a.b": "x"}`) is unreachable in TypeScript and becomes reachable as `a.b` after flattening. No shipped locale file has one; the plan accepts the difference rather than add an escaping scheme.

The `warn` sink stays the crate default (stderr). On iOS that lands in the Xcode console, which is where a missing-key warning is useful.

#[derive(Clone, Copy, Debug, PartialEq, Eq, uniffi::Enum)]

    Ltr,
    Rtl,

/// A locale pack. `translations` is flat: a branch's members are spelled
/// `branch.member`, and plural forms `key.one`, `key.other` and so on.
#[derive(Clone, Debug, PartialEq, Eq, uniffi::Record)]
pub struct LocalePack {
    /// BCP-47 code: `en`, `es`, `ar`, `zh-Hans`.
    pub code: String,
    /// Native display name.
    pub name: String,
    /// `None` reads as left to right.
    #[uniffi(default = None)]
    pub dir: Option<TextDirection>,
    pub translations: HashMap<String, String>,
}

fn flatten(dict: &TranslationDictionary, prefix: &str, out: &mut HashMap<String, String>) {
    for (key, node) in dict.iter() {
        let path = if prefix.is_empty() { key.to_string() } else { format!("{prefix}.{key}") };
        match node {
            TranslationNode::Text(text) => {
                out.insert(path, text.clone());
            }
            TranslationNode::Branch(branch) => flatten(branch, &path, out),
        }
    }
}

fn insert_path(
    dict: &mut TranslationDictionary,
    full: &str,
    key: &str,
    text: String,
) -> Result<(), Error> {
    let (head, rest) = match key.split_once('.') {
        Some((head, rest)) => (head, Some(rest)),
        None => (key, None),
    };
    if head.is_empty() {
        return Err(invalid(format!("translation key \"{full}\" has an empty segment")));
    }
    let conflict =
        || invalid(format!("translation key \"{full}\" is both a string and a group of strings"));
    match rest {
        None => match dict.get(head) {
            Some(TranslationNode::Branch(_)) => Err(conflict()),
            _ => {
                dict.insert(head, TranslationNode::Text(text));
                Ok(())
            }
        },
        Some(rest) => {
            let mut child = match dict.get(head) {
                None => TranslationDictionary::new(),
                Some(TranslationNode::Branch(branch)) => branch.clone(),
                Some(TranslationNode::Text(_)) => return Err(conflict()),
            };
            insert_path(&mut child, full, rest, text)?;
            dict.insert(head, TranslationNode::Branch(child));
            Ok(())
        }
    }
}

/// The nested dictionary the plugin reads. Keys are inserted in sorted
/// order, so the result doesn't depend on `HashMap` iteration.
pub fn unflatten(flat: HashMap<String, String>) -> Result<TranslationDictionary, Error> {
    let mut entries: Vec<(String, String)> = flat.into_iter().collect();
    entries.sort_by(|a, b| a.0.cmp(&b.0));
    let mut root = TranslationDictionary::new();
    for (key, text) in entries {
        insert_path(&mut root, &key, &key, text)?;
    }
    Ok(root)
}

impl TryFrom<LocalePack> for Locale {
    type Error = Error;

    fn try_from(pack: LocalePack) -> Result<Self, Error> {
        Ok(Locale {
            code: pack.code,
            name: pack.name,
            dir: pack.dir.map(Dir::from),
            translations: unflatten(pack.translations)?,
        })
    }
}

impl From<&Locale> for LocalePack {
    fn from(locale: &Locale) -> Self {
        let mut translations = HashMap::new();
        flatten(&locale.translations, "", &mut translations);
        LocalePack {
            code: locale.code.clone(),
            name: locale.name.clone(),
            dir: locale.dir.map(TextDirection::from),
            translations,
        }
    }
}

/// Parse a locale file in the web's shape (`{code, name, dir?,
/// translations}`, nested) into a flat pack.
#[uniffi::export]
pub fn locale_pack_from_json(json: String) -> Result<LocalePack, ViewerError> {
    let locale: Locale = serde_json::from_str(&json)
        .map_err(|e| invalid(format!("not a locale pack: {e}")))?;
    Ok(LocalePack::from(&locale))
}

/// A locale as a switcher sees it.
#[derive(Clone, Debug, PartialEq, Eq, uniffi::Record)]
pub struct LocaleInfo {
    pub code: String,
    /// The bare code until a lazy pack has loaded.
    pub name: String,
    pub direction: TextDirection,
    pub loaded: bool,
}

impl From<crate::LocaleInfo> for LocaleInfo {
    fn from(info: crate::LocaleInfo) -> Self {
        LocaleInfo {
            code: info.code,
            name: info.name,
            direction: info.dir.into(),
            loaded: info.loaded,
        }
    }
}

/// A `{slot}` value. A `Number` named `count` picks a plural form.
#[derive(Clone, Debug, PartialEq, uniffi::Enum)]
pub enum I18nParam {
    Text { value: String },
    Number { value: f64 },
}

impl From<I18nParam> for Param {
    fn from(param: I18nParam) -> Self {
        match param {
            I18nParam::Text { value } => Param::Text(value),
            I18nParam::Number { value } => Param::Number(value),
        }
    }
}

fn params(map: HashMap<String, I18nParam>) -> Option<Params> {
    if map.is_empty() {
        return None;
    }
    let mut entries: Vec<(String, I18nParam)> = map.into_iter().collect();
    entries.sort_by(|a, b| a.0.cmp(&b.0));
    let mut params = JsRecord::new();
    for (key, value) in entries {
        params.insert(key, value.into());
    }
    Some(params)
}

/// What a test loader does with a request.
#[derive(Clone, Copy)]
enum Answer {
    Pack,
    Fail,
    Drop,
    Twice,
    Hold,
}

struct Loader {
    answer: Answer,
    asked: Mutex<Vec<String>>,
    held: Mutex<Vec<Arc<LocaleLoadCompletion>>>,
}

impl Loader {
    fn new(answer: Answer) -> Arc<Self> {
        Arc::new(Loader { answer, asked: Mutex::default(), held: Mutex::default() })
    }
}

impl LocaleLoader for Loader {
    fn load(&self, code: String, completion: Arc<LocaleLoadCompletion>) {
        self.asked.lock().unwrap().push(code.clone());
        match self.answer {
            Answer::Pack => completion.finish(pack(&code, &[("hello", "Hola")])),
            Answer::Fail => completion.fail("offline".into()),
            Answer::Drop => drop(completion),
            Answer::Twice => {
                completion.finish(pack(&code, &[("hello", "Hola")]));
                completion.finish(pack(&code, &[("hello", "Second")]));
            }
            Answer::Hold => self.held.lock().unwrap().push(completion),
        }
    }
}

fn handle(config: I18nConfig) -> (KernelThread<TestKernel>, Arc<I18nHandle>) {
    let thread = KernelThread::spawn(move |post| {
        let config = config.into_plugin_config(post)?;
        TestKernel::open(vec![i18n_plugin(config)], one_document())
    })
    .unwrap();
    let post = thread.post();
    let handle =
        block_on(thread.call(move |k| I18nHandle::new(k.capability(&I18N).unwrap(), post)))
            .unwrap();
    (thread, handle)
}

/// Serves lazy packs. Called on the kernel thread: return at once, do the
/// work elsewhere, and answer through `completion` from any thread. A
/// completion dropped unanswered fails the switch with `operation-failed`.
#[uniffi::export(with_foreign)]
pub trait LocaleLoader: Send + Sync {
    fn load(&self, code: String, completion: Arc<LocaleLoadCompletion>);
}

/// The answer to one `LocaleLoader::load`. The first call wins.
#[derive(uniffi::Object)]
pub struct LocaleLoadCompletion {
    settle: ForeignSettle<Locale>,
}

#[uniffi::export]
impl LocaleLoadCompletion {
    /// A pack whose keys don't form a tree (see `LocalePack`) fails the
    /// switch with `invalid-input`.
    pub fn finish(&self, pack: LocalePack) {
        self.settle.settle(move || Locale::try_from(pack));
    }

    pub fn fail(&self, detail: String) {
        self.settle.settle(move || Err(Error::new(detail).with("code", code::OPERATION_FAILED)));
    }
}

/// `i18nPlugin(config)` as Swift configures it.
#[derive(uniffi::Record)]
pub struct I18nConfig {
    /// Startup locale. May name a lazy pack. Defaults to `fallback_locale`.
    #[uniffi(default = None)]
    pub locale: Option<String>,
    /// Tried when a key misses the current locale. Defaults to `en`.
    #[uniffi(default = None)]
    pub fallback_locale: Option<String>,
    /// Packs available at once.
    #[uniffi(default = [])]
    pub locales: Vec<LocalePack>,
    /// Codes `loader` serves on demand.
    #[uniffi(default = [])]
    pub lazy_locales: Vec<String>,
    #[uniffi(default = None)]
    pub loader: Option<Arc<dyn LocaleLoader>>,
}

impl fmt::Debug for I18nConfig {
    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
        f.debug_struct("I18nConfig")
            .field("locale", &self.locale)
            .field("fallback_locale", &self.fallback_locale)
            .field("locales", &self.locales.iter().map(|l| &l.code).collect::<Vec<_>>())
            .field("lazy_locales", &self.lazy_locales)
            .field("loader", &self.loader.is_some())
            .finish()
    }
}

impl I18nConfig {
    /// On the kernel thread: each lazy code becomes a `Loader` that asks the
    /// foreign loader and settles through `post`.
    pub fn into_plugin_config(self, post: KernelPost) -> Result<crate::I18nConfig, Error> {
        let locales =
            self.locales.into_iter().map(Locale::try_from).collect::<Result<Vec<_>, _>>()?;
        let loaders = match (self.lazy_locales.is_empty(), self.loader) {
            (true, _) => None,
            (false, None) => {
                return Err(invalid(format!(
                    "lazy locales {:?} need a loader",
                    self.lazy_locales
                )));
            }
            (false, Some(foreign)) => {
                let mut loaders: JsRecord<Loader> = JsRecord::new();
                for code in self.lazy_locales {
                    let (foreign, post, asked) = (foreign.clone(), post.clone(), code.clone());
                    let loader: Loader = Rc::new(move || {
                        let (promise, resolver) = Promise::pending();
                        let completion = Arc::new(LocaleLoadCompletion {
                            settle: ForeignSettle::new(resolver, post.clone(), "a LocaleLoader completion"),
                        });
                        foreign.load(asked.clone(), completion);
                        Ok(promise)
                    });
                    loaders.insert(code, loader);
                }
                Some(loaders)
            }
        };
        Ok(crate::I18nConfig {
            locale: self.locale,
            fallback_locale: self.fallback_locale,
            locales: Some(locales),
            loaders,
            warn: None,
        })
    }
}

    fn try_from(event: &LocaleLoadFailedEvent) -> Result<Self, Error> {

impl I18nHandle {

#[uniffi::export]
impl I18nHandle {
    /// Current locale, then the fallback, then `fallback`, then the key.
    pub async fn t(
        &self,
        key: String,
        params: HashMap<String, I18nParam>,
        fallback: Option<String>,
    ) -> Result<String, ViewerError> {
        self.cap
            .call(move |c| {
                let options = TranslateOptions { params: self::params(params), fallback };
                Ok(c.t(&key, Some(&options)))
            })
            .await
    }

    pub async fn has_key(&self, key: String) -> Result<bool, ViewerError> {
        self.cap.call(move |c| Ok(c.has_key(&key))).await
    }

    pub async fn locale(&self) -> Result<String, ViewerError> {
        self.cap.call(|c| Ok(c.get_locale())).await
    }

    pub async fn direction(&self) -> Result<TextDirection, ViewerError> {
        self.cap.call(|c| Ok(c.get_direction().into())).await
    }

    pub async fn locales(&self) -> Result<Vec<LocaleInfo>, ViewerError> {
        self.cap.call(|c| Ok(c.list_locales().into_iter().map(LocaleInfo::from).collect())).await
    }

    pub async fn loading_locale(&self) -> Result<Option<String>, ViewerError> {
        self.cap.call(|c| Ok(c.get_loading_locale())).await
    }

    /// Resolves once the locale is usable. Rejects `not-found` for an
    /// unknown code, `operation-failed` when the pack fails to load, and
    /// `operation-cancelled` when a newer call supersedes this one.
    pub async fn set_locale(&self, code: String) -> Result<(), ViewerError> {
        self.cap.call_promise(move |c| Ok(c.set_locale(&code)), |()| ()).await
    }

    pub async fn register_locale(
        &self,
        pack: LocalePack,
    ) -> Result<Arc<RegistrationHandle>, ViewerError> {
        let post = self.post.clone();
        self.cap
            .call(move |c| {
                let remove = c.register_locale(Locale::try_from(pack)?);
                Ok(RegistrationHandle::new(post, move || remove()))
            })
            .await
    }

    /// Merge flat keys into a registered pack; later keys win.
    pub async fn add_translations(
        &self,
        code: String,
        translations: HashMap<String, String>,
    ) -> Result<(), ViewerError> {
        self.cap.call(move |c| c.add_translations(&code, unflatten(translations)?)).await
    }

    /// The listener is registered on the kernel thread after this returns;
    /// a cancel before then still takes effect.
    pub fn subscribe(&self, listener: Arc<dyn I18nEventListener>) -> Arc<Subscription> {
        let (subscription, slot) = Subscription::pending(self.post.clone());
        self.cap.fire(move |c| {
            let changed = {
                let listener = listener.clone();
                c.on_locale_changed(move |event| {
                    listener.on_event(I18nEvent::LocaleChanged { event: event.clone() });
                    Ok(())
                })
            };
            let failed = c.on_locale_load_failed(move |event| {
                let event = LocaleLoadFailure::try_from(event)?;
                listener.on_event(I18nEvent::LocaleLoadFailed { event });
                Ok(())
            });
            slot.fill(Unsubscribe::new(move || {
                changed.call();
                failed.call();
            }));
        });
        subscription
    }
}

```swift
public import EmbedPDFBindings
import Foundation

public typealias I18nConfig = EmbedPDFBindings.I18nConfig
public typealias LocalePack = EmbedPDFBindings.LocalePack
public typealias LocaleInfo = EmbedPDFBindings.LocaleInfo
public typealias TextDirection = EmbedPDFBindings.TextDirection
public typealias I18nParam = EmbedPDFBindings.I18nParam
public typealias I18nEvent = EmbedPDFBindings.I18nEvent
public typealias LocaleChangedEvent = EmbedPDFBindings.LocaleChangedEvent
public typealias LocaleLoadFailure = EmbedPDFBindings.LocaleLoadFailure
public typealias LocaleLoader = EmbedPDFBindings.LocaleLoader
public typealias LocaleLoadCompletion = EmbedPDFBindings.LocaleLoadCompletion

extension LocalePack {
  /// A locale file in the web's shape (`{code, name, dir?, translations}`).
  public static func decode(json: String) throws(PDFError) -> LocalePack {
    do {
      return try localePackFromJson(json: json)
    } catch {
      throw PDFError(error)
    }
  }
}

/// The viewer's locale packs and translations. There is one per viewer and
/// it works before any document opens. Get it with `PDFViewer.i18n()`; the
/// viewer needs `ViewerConfig(i18n: I18nConfig(...))`.
public struct I18nCapability: Sendable {
  let handle: I18nHandle
  let viewer: PDFViewer

  /// The current locale, then the fallback locale, then `fallback`, then the
  /// key itself. A `.number` named `count` picks a plural form.
  public func t(_ key: String, params: [String: I18nParam] = [:], fallback: String? = nil)
    async throws(PDFError) -> String
  {
    try await bridged { try await handle.t(key: key, params: params, fallback: fallback) }
  }

  public func hasKey(_ key: String) async throws(PDFError) -> Bool {
    try await bridged { try await handle.hasKey(key: key) }
  }

  public func locale() async throws(PDFError) -> String {
    try await bridged { try await handle.locale() }
  }

  public func direction() async throws(PDFError) -> TextDirection {
    try await bridged { try await handle.direction() }
  }

  /// Registered packs, then lazy ones not loaded yet.
  public func locales() async throws(PDFError) -> [LocaleInfo] {
    try await bridged { try await handle.locales() }
  }

  public func loadingLocale() async throws(PDFError) -> String? {
    try await bridged { try await handle.loadingLocale() }
  }

  /// Returns once the locale is usable. Throws `not-found` for an unknown
  /// code, `operation-failed` when the pack fails to load and
  /// `operation-cancelled` when a newer call supersedes this one.
  /// Cancelling the task doesn't cancel the switch.
  public func setLocale(_ code: String) async throws(PDFError) {
    try await bridged { try await handle.setLocale(code: code) }
  }

  /// Dropping the registration keeps the pack; `unregister()` removes it.
  public func register(_ pack: LocalePack) async throws(PDFError) -> Registration {
    Registration(handle: try await bridged { try await handle.registerLocale(pack: pack) })
  }

  /// Flat keys (`"zoom.in"`); later keys win.
  public func addTranslations(_ translations: [String: String], to code: String)
    async throws(PDFError)
  {
    try await bridged { try await handle.addTranslations(code: code, translations: translations) }
  }

  /// Finishes when the viewer is destroyed.
  public var events: AsyncStream<I18nEvent> {
    viewer.registry.stream { handle.subscribe(listener: $0) }
  }
}

extension EventRelay: I18nEventListener where Event == I18nEvent {
  func onEvent(event: I18nEvent) {
    continuation.yield(event)
  }
}

extension PDFViewer {
  public func i18n() async throws(PDFError) -> I18nCapability {
    let handle = try await bridged { try await host.i18n() }
    return I18nCapability(handle: handle, viewer: self)
  }
}

/// Serves lazy packs from `<code>.json` files in a bundle, in the web's
/// locale file shape. Reads off the kernel thread.
public final class BundleLocaleLoader: LocaleLoader, @unchecked Sendable {
  let bundle: Bundle
  let subdirectory: String?

  public init(bundle: Bundle = .main, subdirectory: String? = nil) {
    self.bundle = bundle
    self.subdirectory = subdirectory
  }

  public func load(code: String, completion: LocaleLoadCompletion) {
    let (bundle, subdirectory) = (bundle, subdirectory)
    DispatchQueue.global(qos: .userInitiated).async {
      guard let url = bundle.url(forResource: code, withExtension: "json", subdirectory: subdirectory) else {
        completion.fail(detail: "no \(code).json in \(bundle.bundlePath)/\(subdirectory ?? "")")
        return
      }
      do {
        let json = try String(contentsOf: url, encoding: .utf8)
        completion.finish(pack: try LocalePack.decode(json: json))
      } catch {
        completion.fail(detail: "\(error)")
      }
    }
  }
}
```
